# Miranda Leão Advocacia

Estrutura inicial do projeto da landing page institucional da Miranda Leão Advocacia. O futuro site deverá apresentar o escritório e suas áreas de atuação, transmitir confiança, explicar o atendimento, responder dúvidas recorrentes e facilitar o contato pelo WhatsApp.

O projeto utiliza somente HTML, CSS e JavaScript, sem frameworks.

## Estrutura

```text
assets/
  images/           Imagens que serão utilizadas no site
  logo/             Arquivos finais do logotipo
  icons/            Ícones e elementos gráficos
docs/
  briefing.md       Informações consolidadas do cliente e do projeto
  brand-direction.md
                     Direção visual e critérios de identidade
  content-structure.md
                     Proposta inicial das seções e do conteúdo
  project-notes.md  Pendências, observações e diretrizes
index.html          Estrutura HTML mínima
style.css           Ponto de entrada dos estilos
script.js           Ponto de entrada das interações
README.md           Visão geral do projeto
```

## Estágio atual

A primeira versão completa da landing page foi desenvolvida. Ela inclui navegação responsiva, apresentação institucional, áreas de atuação, etapas do atendimento, perguntas frequentes, diferenciais, chamada para contato e rodapé.

O site é responsivo, utiliza HTML semântico e oferece interações acessíveis para o menu móvel e o FAQ. O wordmark e os espaços visuais são provisórios até o recebimento do logotipo e das fotografias profissionais.
